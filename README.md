# ZOMBO · After the Fall

Telegram Mini App + Telegram-бот, Python 3.11, FastAPI, PostgreSQL/SQLite, чистый адаптивный фронтенд.

## Обновление 0.2 · Деревья талантов

- **4 класса × 3 ветки × 3 умения:** 36 разных узлов и до 108 рангов (по 27 рангов доступно каждому герою).
- Уровни навыков 1/3 → 3/3, зависимости по рангу и уровню героя (1 / 5 / 12); каждый путь можно развивать независимо.
- +2 очка талантов при создании героя; +1 каждые два уровня; дополнительные очки на уровнях, кратных 5.
- Все усиления работают на сервере: сила/криты/точность, восстановление энергии, HP и лечение, защита/уклонение, вампиризм, лут, крышки, опыт и удары по боссу.
- Четыре классовых боевых приёма: **Второе дыхание / Двойной выстрел / Шквал клинков / Дымовая завеса**. Проверка изучения, расхода энергии и восстановления (3 хода) на сервере.
- Отдельный мобильный экран талантов: 3 вкладки, линии прогресса, блокировки, описание эффекта, свободные очки, суммарные усиления, доступность.
- Сброс талантов с возвратом всех очков: первая попытка бесплатная, следующие за крышки, во время боя запрещён.
- **Безопасное обновление существующих игроков:** очки компенсируются один раз при входе, старые навыки и инвентарь сохраняются. Миграций и очистки базы не требуется.

## Реализовано в стартовой версии

- Авторизация Telegram WebApp `initData` с криптографической проверкой на сервере, классы Врач / Коп / Убийца / Вор, отдельные рисованные портреты и развёрнутые деревья талантов для каждого класса.
- Профиль, прокачка статов/навыков, опыт, уровни, здоровье, энергия, рюкзак, экипировка.
- 6 локаций, сбор ресурсов, PvE-бои с выбором зоны, лечение, защита, побег, смерть и штрафы.
- Ежедневные награды, квесты, крафт, торговец, рынок обмена игрок-игрок, топ игроков.
- PvP-вызовы 1v1 по ходам, рейтинговая система, группировка в кланы до 25 игроков, казна, захват 4 территорий.
- Общий босс, рейтинг урона, ротация раз в 3 дня; Telegram-бот: /start /help /profile /daily, Telegram Mini App кнопка.
- Реальные инвойсы Telegram Stars на пакеты премиум-валюты; зачисление **только** после `successful_payment` и с проверкой idempotency. За Zombo уже покупаются VIP (7/14/30 дней), буст XP и шанс добычи на 24 часа.
- Авторизация админ-сводки для `ADMIN_IDS`, CORS не открыт, токен только в env.

## Railway

Создайте PostgreSQL в проекте и подключите к сервису переменную `DATABASE_URL=${{Postgres.DATABASE_URL}}`.

Секреты: `BOT_TOKEN`, `TELEGRAM_WEBHOOK_SECRET` (случайный длинный секрет), `PUBLIC_URL=https://<domain>`, `ADMIN_IDS=...`, `DEMO_MODE=0`. Порт берётся из `PORT`. Healthcheck: `/health`.

После назначения `PUBLIC_URL` сервер на старте автоматически вызывает `setWebhook` и `setChatMenuButton`.

Для локального тестирования:

```bash
python -m venv .venv && source .venv/bin/activate
pip install -r requirements.txt
export DATABASE_URL=sqlite:///./zombo.db
export DEMO_MODE=1
uvicorn app:app --reload
```
Откройте `http://localhost:8000/?demo=1`. Не включайте `DEMO_MODE=1` на публичном сервере: он позволяет получить доступ к тестовым аккаунтам без Telegram.

```bash
pytest -q tests/
```

## Правило хранения токенов

Никогда не коммитьте реальный `BOT_TOKEN`. Если токен уже опубликован в чате/скриншоте, сбросьте его через @BotFather и обновите переменную Railway.


## Территориальные клановые войны (v0.3)

Настройка расписания: `WAR_TIMEZONE=Europe/Moscow` (IANA-часовой пояс, по умолчанию МСК). Это **локальное время указанной зоны**, а не часовой пояс Railway.

- **Понедельник, среда, пятница 00:00–23:59:** торги за территорию. Ставка от 100 крышек только из казны клана; ставить и повышать могут лидер и назначенный воевода. У кого ставка выше — претендент на территорию. При перебитии предыдущая ставка возвращается в казну; при повышении собственной списывается только разница.
- **Вторник, четверг, суббота с 00:00:** результат ставок фиксируется. Свободная территория переходит победителю без боя. Если есть владелец, назначается КВ.
- **10:00–15:00:** лидер или воевода выставляет до 25 участников своей стороны из собственного клана. Одного бойца нельзя записать в несколько КВ одного дня.
- **16:00–16:30:** КВ на 30 одноминутных раундов с автоматическими столкновениями назначенных бойцов. Участник дополнительно может раз за раунд атаковать, защищаться или лечить себя (последнее доступно врачу). Когда все бойцы одной стороны выбиты, бой заканчивается досрочно; в 16:30 выигрывает сторона с большим оставшимся HP. При равенстве защитник удерживает землю.
- **Налог:** 1% крышек с награды за убийство зомби в контролируемой зоне удерживается у игрока. Дробная часть накапливается по территории (целые крышки без потери округления), налог поступает в резерв и автоматически переносится в казну каждые 5 часов. При смене владельца резерв сперва перечисляется старому владельцу.

Локации и налоговые территории: `forest→bridge`, `city→tower`, `factory→depot`, `hospital→clinic`, `wasteland→depot`. Назначение зон настраивается через `LOCATION_TERRITORY` в `clan_wars.py`. Полностью нейтральные зоны налог не собирают.

Автозапуск: встроенный фоновый цикл FastAPI раз в 25 секунд проверяет сроки сбора налогов, фиксации ставок и раунды войны. Важные временные отметки сохраняются в PostgreSQL, поэтому после перезапуска работы догоняются; на Railway сервис должен работать постоянно (не в режиме sleep). Таблицы `territory_wars`, `war_fighters`, `clan_officers`, `territory_taxes` создаются автоматически без изменения схем существующих персонажей.

Если изменится расписание, сначала учитывайте открытые ставки и незавершённые войны. Игровую валюту/клановые роли на продакшене проверяйте после деплоя.
